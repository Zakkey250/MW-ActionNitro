# アクションナイトロ 0.1.0-alpha.7

NFS Most Wanted (2005) の自然NOS回復を、運転アクションによる回復に置き換える独立ASIです。

[ダウンロード](https://github.com/Zakkey250/MW-ActionNitro/releases) · [English](README.md)

## 回復項目

| 項目 | 標準回復量 |
| --- | --- |
| ニアミス／対向車ニアミス | 100／200pt |
| 対向車線 | 1m＝1pt |
| スリップストリーム | 1m＝2pt |
| ジャンプ／滞空 | 100pt／毎秒40pt |
| ドリフト | 速度・角度に応じ毎秒50～100pt |
| ドリフト継続 | 3秒ごとに追加100pt |
| 連続ニアミス | 50ptずつ増加、追加最大200pt |
| トップスピード | 車両の計算上最高速度の75%以上で、ゲージの毎秒4% |

100pt＝NOS使用可能時間0.3秒が既定です。トップスピードの量は純正HP Remasteredの警察側設定を基準とし、時間はシミュレーション時間です。NOS使用中、衝突、ポーズ、ロード、無効な車両データ等では回復を抑制し、満タンを超えません。

ゲーム本来のChargeNOS関数で内部残量に加算するため、純正HUDとCustomHUDは共通の数値を参照します。別のテキストHUDには実際に加算された項目とポイントを表示します。物理的な横滑り判定に加え、任意導入のMW Arcade Driftから確定ドリフト状態を読めます。相手MODの物理・設定は変更しません。

## 導入・更新

単一ASIで、確認済みのRedux 3.04（英語1.3・4GB版）とNFSPatcher版の英語1.3 EXE／4GBパッチ版に対応します。正確なEXE識別条件は[互換性一覧](COMPATIBILITY.md)を参照してください。異なるEXEはフック前に拒否します。多言語表示対応は、各地域版EXEへの対応を意味しません。既存ASIローダーが必要です。

1. ゲームを終了し、リリースZIPを展開します。
2. PowerShellで `Install.ps1 -GameDirectory "ゲームのフォルダー"` を実行します。書き込み権限が必要です。
3. 通常の起動方法でゲームを起動します。

インストーラーはEXEを確認し、このMODの旧ASI/INIをバックアップして、既存INIの値を保持したまま不足設定だけ追加します。新規導入は `ObserveOnly=0` で有効です。旧設定が1なら観測専用のままなので、実回復させる場合は0に変更してください。

手動導入の場合はASIをゲームのscriptsへコピーします。INIは新規導入時のみコピーし、更新時は設定を統合してください。既存dinput8.dll、他MOD、ゲーム資産、セーブの置き換えは不要です。アンインストールはゲーム終了後に本MODのASI/INIを削除し、戻す場合はActionNitro-backupsから旧版を復元します。

## 全言語表示

導入対象ゲームにある15種類のテキスト言語に、英語UK・簡体字中国語・タイ語の選択肢を加えた計18種類に対応しています。回復項目、更新通知本文、ボタンを翻訳済みです。

`en`, `en-GB`, `fr`, `de`, `it`, `es`, `es-MX`, `nl`, `sv`, `da`, `fi`, `pl`, `ru`, `ja`, `ko`, `zh-TW`, `zh-CN`, `th`

`[HUD] Language=auto` はWidescreen Fixの言語指定、Widescreen FixのWriteSettingsToFile有効時のローカルSettings.ini、ゲームの32bitレジストリ、ネイティブ言語表のファイル名の順で選び、不明なら英語にします。日本語Bridgeで英語EXEを使う構成にも対応します。`Language=ja` 等で固定もできます。設定変更後は再起動してください。

Windowsの言語別フォントを使い、長い項目は縮小して行幅に収めます。CJK・タイ語は対応Windowsフォントが必要です。ゲームのフォント資産は変更しません。翻訳は本MOD用の表記で、公式ゲームから抜き出した文章ではありません。HUDはRight/Bottom/Widthで配置を調整できます。CustomHUDのメーター位置への自動追従はありません。

## 更新通知

`[Updates] Enabled=1` で起動時に一度GitHubを確認します。`Language=auto` はHUD言語に従い、個別指定も可能です。無効化は `Enabled=0` です。

他の自作MODと共通の通知待ち合わせ方式を使用します。新しい版番号と対応する公開済みバイナリZIPがある場合のみ通知し、走行中は表示しません。通信と通知は初期化ワーカーで行い、描画・物理スレッドでは行いません。オフラインでもゲームは継続します。GitHubボタンはクリックした時のみリリースページを開き、自動ダウンロード・自動導入はしません。

## alpha.6の変更と検証

- 18種類の言語表示、フォント選択、長文の幅調整を追加。
- 起動時更新通知を追加。
- ドリフト・車線の診断ログを各項目最大毎秒4回へ集約。短い状態変化は件数と状態ビット集合に残します。
- 既存GDIキャッシュ、表示行数に応じたテクスチャ転送、数値表示の最大10Hz更新を維持。
- 承認済みのアクション判定・回復量は維持。ArcadeDrift本体は本更新では変更しません。

報酬計算、5000回のx86フック試験、対象外EXE拒否、18種類の文字・描画検査、更新通知92チェック、D3D9ピクセル比較・状態復元・Reset試験が通過しています。言語表示と通知の実ゲーム内確認、FPSの改善量の実測は未完了です。独立描画テストを実ゲームFPSの改善と見なしません。

スリップストリームは道路境界で切れる場合があり、遮蔽物のレイキャストはありません。ニアミスは一般交通車が対象です。対向車線は道路情報が不明な場所・接続区間等を除外します。HUDの位置と他MODの組合せは実ゲームで確認してください。

## ビルド

Visual Studio Build Tools 2022、v143、Windows SDK、Win32、C++17で `tools/Build.ps1` を実行します。ゲームを起動せず隔離試験を実施します。Pythonの追加検証はpefile/capstone/unicornと各自のゲーム導入先が必要です。

第三者コードはMinHookとnlohmann/jsonで、それぞれのライセンスを保持しています。ゲーム資産やEXEは配布物に含めません。

## alpha.7：Redux/Main共通ASI

Redux 3.04の確認済みEXEをサイズとSHA256の組で識別します。フック箇所の保護検査は維持し、判定・回復量・描画を変更せず、専用の別ASIも不要です。ReduxのSAVE内Settings.iniを参照し、同じPCのMain側レジストリ言語を誤って優先しないようにしました。

両環境の実EXEを出荷用SHA256処理で確認し、11箇所の静的検査とReduxの3260件のネイティブ車線選択比較、隔離ビルド・試験が通過しました。Reduxでの起動時フック共存、NOS/HUD表示、試走の確認は未実施です。
